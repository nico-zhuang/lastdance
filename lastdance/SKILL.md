# Last Dance｜最后一遍

这是一道交付前的最后编辑工序。目标不是把文字写得更花，也不是把方案重新策划，而是让已有内容说清楚该说的事，删掉不承担信息的部分。

## 输出契约

默认只输出清洗后的正文。

- 不复述原文。
- 不解释改了什么。
- 不列 AI 味问题。
- 不加“以下是优化版本”“希望对你有帮助”等套话。
- 保留用户原有的标题层级、列表、表格、项目名和必要排版。

只有用户明确要求“标问题”“说明修改”“给对照”时，才改变上述输出形式。

用户说 `Last Dance review`、`终稿审稿` 或明确要求风险提示时，输出「清洗后正文」和「请你确认」两部分。后一部分只列不能安全清洗的内容，例如语域不明、锁定文本、无来源引用或可能改变承诺范围的句子；不输出逐句对照和修改过程。

## 适用边界

适用于内容与结构已基本完成的：方案、PPT 页面文案、周报、汇报、邮件、演讲稿、对外介绍、README 和操作说明。

不把这份 skill 当作以下任务的替代品：

- 从零写方案、补研究、做事实核查或重新规划结构。
- 逐字翻译、法律/合同定稿、保留原文措辞的校对。
- 以虚构案例、数字、客户反馈或执行动作来填补原文的信息空缺。

🔴 CHECKPOINT：如果用户明确要清洗，但给的是提纲、零散需求或明显未完成的草稿，先停下，只问：`这还是个提纲。要我先补成稿，还是只顺一顺现有的句子？`

## 保护对象

先静默圈出以下内容，除非原文自相矛盾或用户要求改动，否则不删除、不改写其含义：

- 数字、日期、金额、比例、版本号、链接。
- 项目名、公司名、人名、产品名、专有术语、字段、命令、代码、引用。
- 责任主体、条件、风险、待确认项、边界和承诺。
- 表格结构、步骤顺序、层级关系和已确认的结论。

## 锁定文本

以下内容默认视为不可改动文本：法规、合同、政策原文、审批口径、客户或领导的直接引语、媒体引述，以及用户标注“原文不可动/定稿/引用”的内容。

锁定文本保留字面原样；只清理其前后的解释文字。若整段几乎都是锁定文本，保持原样，不为了完成清洗而改写。

## 关键数字与来源

Last Dance 不是事实核查工具。不搜索资料、不补来源，也不因为一句话看起来夸张就删数字或改弱结论。

只根据本次输入中看得到的来源标识判断，例如脚注、链接、附件名、数据出处或“来源：”字段。正文里没带来源，不等于整份材料没有来源。

普通清洗时，保留关键数字和原有确定性，不追问、不加提示。不要把“达到 10–100 倍”改成“可提升 10–100 倍”，也不要改成“预计”“可能”。

🔴 CHECKPOINT：用户要求 `Last Dance review`、`终稿审稿`、`对外发布前检查`，且句子同时满足以下条件时，暂停并只问一句：

1. 是会影响正式材料可信度的外部事实、比例、倍数、预测或研究结论；
2. 本次输入内没有可见来源标识；
3. 不是内部已确认的日期、预算、负责人、进度或任务。

提问格式：`“<关键数字或结论>”的来源确定吗？不确定的话，我先不动这句。`

用户确认来源无误后，按普通规则清洗。用户说来源不确定或不回答时，保留该句字面原样；只清理不影响这项主张的周边文字。

## 场景路由

先按正文信号静默选择一个主场景。

| 场景 | 信号 | 编辑重心 |
| --- | --- | --- |
| 方案 / PPT | 标题、主张、路径、预算、招商、执行 | 标题直白；概念落到对象、动作、条件与结果；不编造执行项。 |
| 内部汇报 / 周报 | 本周完成、下周计划、进度、风险、负责人 | 保留时间线与责任；删功劳话、过程旁白和重复结论。 |
| 对外文案 | 品牌、产品介绍、邀请、公开文章 | 压低宣传腔；以事实和具体利益替代“领先、焕新、赋能”等词。 |
| 技术 / 操作文档 | 步骤、接口、配置、故障、说明 | 术语稳定、步骤可检索；不为口语化而改字段、命令或系统主语。 |
| 品牌 / 演讲表达 | 品牌主张、活动主题、广告标题、演讲开场、明确要求有传播性 | 保留有意的张力和记忆点；只清理模板感、假概念和无事实支撑的拔高。 |

🔴 CHECKPOINT：如果文本同时像严肃交付与品牌表达，且两种处理会导致“保留张力”或“压低语气”的不同结果，暂停并只问一句：`这段最后放进正式材料，还是拿去讲、拿去传播？`

如果无法判断但两种处理不会改变结论，按严肃交付处理。

## 执行流程

### 1. 判断编辑范围

默认使用标准清洗：允许删纯空句、合并重复句、调整短标题和修复割裂换行；不改变段落顺序和信息结构。

用户明确说“重写”“大改”“结构也可以动”时，才允许重排段落。

用户明确说“不要删”“保留句数/版式”时，只做句内清洗，不删整句、不合并句子。

用户明确要求保留品牌感、传播性、气势或演讲力度时，使用“品牌 / 演讲表达”场景：保留原文中由具体事实、明确立场或有意节奏支撑的张力；不把它洗成说明书。

品牌 / 演讲表达场景同样不得新增画面、受众反应、结果或情绪判断。原文只写“唤醒城市活力”时，不改写成“让城市重新热闹起来”；没有事实支撑时，宁可删掉模板化修饰，也不补一个更好听的新说法。

### 2. 先删不承担信息的部分

优先处理：

- 开场套话、元评论、谄媚和空收尾。
- 同一结论的重复说法。
- 没有来源的权威垫话，例如“研究表明”“行业普遍认为”。
- 空泛拔高，例如“具有重要意义”“开启新篇章”“为未来奠定基础”。
- 纯概念堆叠，例如“能力底座、生态链接、增长空间、协同闭环”。
- 为凑全面而硬列三项，或把一件事拆成多句同义话。

把“接下来，我想介绍/和大家探讨”“值得注意的是”“本次内容将围绕”等引入句视为开场套话；后面如果有实质内容，直接从实质内容开始。

### 3. 把抽象话落回原文已有的信息

当原文已经给出对象、动作、条件或结果时，优先用它们替代抽象表达。

| 不清洗成 | 清洗为 |
| --- | --- |
| “形成招商转化闭环” | 原文已有的报名、分级、跟进、考察等具体链路。 |
| “打造产业生态入口” | 原文已有的活动、空间、服务或合作动作。 |
| “强化品牌认知” | 原文已有的传播物料、触达对象、发布渠道或效果。 |

原文没有具体信息时，不补写。把语气降回保守陈述，或保留该判断的最短版本。

### 4. 改写高频 AI 结构

- `不是 X，而是 Y`、`不仅 X，更 Y`：多数情况下删掉前半句，直接说 Y；只有前后确实构成必要对比时保留。
- `从 X 到 Y`：只有两端在同一可比较尺度上才保留；否则改成实际覆盖项。
- `通过……实现……`：把主语、动作和对象说清楚；避免连续的“通过”。
- `作为/标志着/彰显/赋能/引领/构建/打造`：若普通动词或“是/有/做”更准确，就换回普通表达。
- 口号式标题：在严肃交付场景改为内容标签，或正文已支持的具体判断；在品牌 / 演讲表达场景，只删除模板化、无事实支撑或可任意替换的部分，保留有意的表达张力。
- 结尾感悟：正文信息说完即停，不补价值升华。

### 5. 统一语域与版面节奏

- 严肃方案和汇报保持克制，不强行口语、幽默、第一人称或情绪化表达。
- 句子读起来要自然，但不通过碎句、过多换行或同义词轮换来制造节奏。
- 标题尽量短，避免不必要换行；不得为了排版把完整意思切断。
- 列表项目保持同一层级；列表若全是完整句，保留必要主语和动作。

### 6. 交付前回读

按顺序检查：

1. 数字、名称、责任人、日期、限制条件，以及跟进对象和承诺范围是否仍在；不得把“每位客户”收窄成“入驻意向”。
2. 每段是否比原文更直接，而不是更短但更空。
3. 是否还残留假二分、口号标题、无源权威、概念堆叠、重复收尾。
4. 是否新增了原文没有的事实、承诺、案例、数据或观点。
5. 在审稿或对外发布前检查中，是否漏掉了需要确认来源的关键外部数字或结论。
6. 是否只留下了正文。

## 失败模式与恢复

| 触发条件 | 一线处理 | 仍无法处理时 |
| --- | --- | --- |
| 文本缺少具体信息，无法把概念改成行动 | 删空泛修饰，保留最短的原判断 | 不编造动作；保持保守表述。 |
| 术语看起来像 AI 腔，但可能是业务专名 | 保留术语，只清理其周围的空话 | 原样保留该词，避免误改业务含义。 |
| 长文中某句可能是有意留白或政治表述 | 不删，只做句内降调 | 保留原句。 |
| 用户要求完全保留版式或句数 | 禁止删句、合并和重排 | 只替换句内冗词，并保留换行。 |
| 审稿或对外发布前检查中出现影响可信度的外部数字或结论，本次输入未见来源标识 | 只问“`<关键数字或结论>`的来源确定吗？不确定的话，我先不动这句。” | 不搜索、不补来源、不降调；用户未确认则保留该句原样。 |
| 清洗后变得过度口语、轻浮或像个人随笔 | 把语气收回到原场景的正式度 | 优先事实句和清晰句，不加个性。 |
| 严肃交付与品牌 / 演讲表达无法区分，且会改变删改力度 | 🛑 STOP，询问文本主要用途 | 收到答案前不清洗有争议的张力句。 |
| 出现法规、合同、政策、审批口径、直接引语或“原文不可动” | 视为锁定文本，保留原样 | 只清理前后解释；整段锁定则原样交付。 |

## 反例黑名单

绝不要这样做：

1. 为了“像人”虚构经历、用户反馈、案例、数据或情绪。
2. 为了删废话而删掉数字、条件、责任人、风险或待确认项。
3. 把“去 AI 味”理解成强行口语化、加幽默、加第一人称或制造不完整句。
4. 把每个抽象词都替换成更生硬的书面同义词。
5. 用新的口号替换旧口号，或把标题写成对仗句、广告语。
6. 因为原文缺少执行细节，就擅自补充“谁来做、何时做、怎么验收”。
7. 输出诊断报告、修改说明或旧稿，除非用户明确要求。
8. 在正文末尾添加总结、价值升华或客服式结束语。
9. 把品牌主张、广告标题或演讲开场一律洗成平淡说明书。
10. 改动法规、合同、审批口径、直接引语或标记为不可改动的文本。
11. 因为数字或外部结论没有在当前段落附来源，就擅自删除、降调、补来源或改成“可能”。
